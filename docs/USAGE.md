# 使用指南

## 创建和加载项目

首次启动会打开演示项目。通过 **新建** 重置为演示参数，或通过 **打开** 读取已有 JSON 项目。在组件树选择项目属性，可编辑项目名称和备注。

项目内部采用 SI 单位。界面会把常用字段显示成 mm、g 或 MPa，单位标在字段旁。轴向位置从头锥尖端向尾部为正。质量分项填写箭体及载荷质量，发动机干质量和推进剂质量在发动机页分别填写。

## 发动机曲线

CSV 需要 `time_s,thrust_n` 两列，可附 `remaining_propellant_kg`。首个时间点应为零，后续时间严格递增，首尾推力为零。选填的剩余质量应从初始推进剂质量单调降至零。导入包含多条记录的 RASP `.eng` 文件时，在对话框选择所需记录。

准稳态模式在界面显示当前参数的单位和压力适用区间。曲线模式缺少室压时，结构校核可使用单独输入的表压。表压为空且没有计算室压时，界面显示该校核未计算。

## 仿真和报告

在 **飞行仿真 → 仿真条件** 填写导轨、海拔与回收条件。仿真高度以发射点为零，大气计算使用绝对海拔。可选择顶点延时开伞、下降至指定高度开伞，或不使用降落伞。

修改参数后需要重新运行仿真，才能导出与当前参数对应的结果。导出的目录包含：

| 文件 | 内容 |
| --- | --- |
| `report.html` | 概要、事件、图表与本次输入，可以离线打开并打印 |
| `project.json` | 可重新加载的项目 |
| `result.json` | 完整数值结果 |
| `flight.csv`、`motor.csv`、`events.csv` | 飞行、发动机和事件时序 |
| `flight.png`、`motor.png`、`stability.png` | 导出图表 |

项目格式仍为 `schema_version: 1`。新版可打开旧版项目，旧的发动机与结构来源备注会在读取时忽略。项目名称和一般备注仍可编辑。
